# ことばのノート · Korean Flashcards

韓国語を見て、声を聴いて、意味を確かめるフラッシュカードです。

**サイト： https://haxitas.github.io/korean-flashcards/**

静的教材とブラウザ内保存だけで動作します。Firebase、ログイン、学習状態の端末間同期、AI APIは使いません。架空サンプルに加えて、明示的に公開を依頼された動画由来の抽出教材を収録します。既存の배の梨・船・腹は別語義として保持します。

## 使い方
「動画・教材から単語帳を選ぶ」に動画タイトル・枚数・元動画リンクを表示します。「この単語帳で学ぶ」を開くと、その動画のカードだけを表示します。選択中のタイトルと元動画リンクも学習画面に残ります。「すべての単語」では、各カードの由来デッキとリンクを確認できます。`?deck=UUID` のURLを共有すると直接その単語帳を開けます。存在しないIDでは案内を表示し全単語へ戻ります。

デッキまたは「すべての単語」を選び、韓国語・日本語・英語で検索できます。カードをタップ／Enter／Spaceで反転すると日本語訳と英語訳を表示します。発音ボタンは独立しています。学習状態は未学習・要復習・覚えたから選び、検索・絞り込み・シャッフルで学習できます。

## 動画教材：コンビニで買い物
[元動画](https://www.youtube.com/watch?v=IGEj-oDKyw8)：「If You’re a BEGINNER, WATCH THIS! | Comprehensible Korean Input at a Convenience Store」。提供された文字起こしから68語・表現を抽出しました（新規67枚、既存안녕하세요を1枚再利用）。全体は73カード・3デッキ・76所属です。

音声は未確認。カタカナは見出しの読みの補助です。価格・数量の食い違い、誤認識らしい語は教材のお知らせに記録しています。빨대・비닐・수프の元表記はsource_cardに残し、要確認を付けています。分割字幕をつないだり表記を整えた短い例文はすべてgeneratedです。字幕全文は公開していません。

学習状態はこのブラウザに保存されます。ブラウザデータ消去に備え、「端末の完全バックアップ・復元」から全教材・ID・所属・状態・表示設定を保存してください。個人バックアップをこのリポジトリに追加しないでください。

音声はブラウザ提供の韓国語音声を使い、オンライン音声は通信を伴う場合があります。端末によって声や品質が異なります。アプリには有料音声契約・支払い処理はありません。

## 教材の更新
教材追加・訂正はCodex経由で `docs/data/catalog.json` を更新し、PRでレビューします。UUIDは一度生成したものを維持します。学習状態は教材更新後も同じUUIDに紐づきます。詳細は [管理手順](tools/README.md) を参照してください。

**PRを作成しただけでは配信は変わりません。** mainへマージし、GitHub Pagesの配信が完了した後に再読み込みしてください。公開教材は誰でも取得できるので、公開可能な内容だけを追加してください。許可された抽出語彙・訳・短い出典例は掲載できますが、個人の学習記録、バックアップ、字幕全文、鍵やトークンをコミットしないでください。

## バックアップの優先関係
復元は20 MiBまで。全件のID・参照を検証し、確認チェック後に同IDを上書きします。バックアップにない既存データは残します。復元した教材は端末内で保護され、そのIDへの配信側訂正も自動では反映しません。

配信教材へ戻したい場合は「配信教材の最新版に戻す」を確認して実行します。カタログにあるIDだけ保護を解除し、学習状態とカタログにない教材は残します。旧Phase 0データは自動削除せず、確認付き移行を提供します。1タブずつ操作してください。

ローカルURLと公開URLは保存領域が別です。公開サイトへ自動移行・送信しません。必要ならローカルで完全バックアップを保存し、公開サイトで明示復元してください。同じGitHub Pagesホスト上の他サイトとWeb Storageのオリジンを共有するため、機密情報の保管用途ではありません。

## 開発と検証
ビルド・npm不要。リポジトリ直下で以下を実行し、http://127.0.0.1:8000/ を開きます。

```sh
python -m http.server 8000 --bind 127.0.0.1 --directory docs
```

ブラウザテストは `/tests/run-tests.html`。管理環境では `node tools/run-tests.mjs`、教材検証は `node tools/catalog.mjs validate --catalog docs/data/catalog.json`。Nodeで48項目、ブラウザでDOM検証を加えた50項目の回帰テストを含みます。iPhone/iPad実機・音声品質は未確認です。

Pagesはmainブランチの `/docs` を配信し、`.nojekyll` を配置しています。管理用ファイルは配信フォルダ外です。教材生成用プロンプトは [CARD_GENERATION_PROMPT.txt](CARD_GENERATION_PROMPT.txt) を利用してください。
