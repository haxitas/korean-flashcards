# ことばのノート · Korean Flashcards

韓国語を見て、声を聴いて、意味を確かめるフラッシュカードです。

**サイト： https://haxitas.github.io/korean-flashcards/**

静的教材とブラウザ内保存だけで動作します。Firebase、ログイン、学習状態の端末間同期、AI APIは使いません。架空サンプルに加えて、明示的に公開を依頼された動画由来の抽出教材を収録します。既存の배の梨・船・腹は別語義として保持します。

## 使い方
「動画・教材から単語帳を選ぶ」に動画タイトル・枚数・元動画リンクを表示します。「この単語帳で学ぶ」を開くと、その動画のカードだけを表示します。選択中のタイトルと元動画リンクも学習画面に残ります。「すべての単語」では、各カードの由来デッキとリンクを確認できます。`?deck=UUID` のURLを共有すると直接その単語帳を開けます。存在しないIDでは案内を表示し全単語へ戻ります。

デッキまたは「すべての単語」を選び、韓国語・日本語・英語で検索できます。カードをタップ／Enter／Spaceで反転すると日本語訳と英語訳を表示します。発音ボタンは独立しています。学習状態は未学習・要復習・覚えたから選び、検索・絞り込み・シャッフルで学習できます。

## 動画教材：コンビニで買い物
[元動画](https://www.youtube.com/watch?v=IGEj-oDKyw8)：「If You’re a BEGINNER, WATCH THIS! | Comprehensible Korean Input at a Convenience Store」。提供された文字起こしから68語・表現を抽出しました（新規67枚、既存안녕하세요を1枚再利用）。全体は73カード・3デッキ・76所属です。

音声は未確認。カタカナは見出しの読みの補助です。価格・数量の食い違い、誤認識らしい語は教材のお知らせに記録しています。빨대・비닐・수프の元表記はsource_cardに残し、要確認を付けています。分割字幕をつないだり表記を整えた短い例文はすべてgeneratedです。字幕全文は公開していません。

学習状態はこのブラウザに保存されます。ブラウザデータ消去に備え、「端末の完全バックアップ・復元」から全教材・ID・所属・状態・表示設定を保存してください。個人バックアップをこのリポジトリに追加しないでください。

音声はブラウザ提供の韓国語音声を使い、オンライン音声は通信を伴う場合があります。端末によって声や品質が異なります。アプリには有料音声契約・支払い処理はありません。

## 教材の更新
教材追加・訂正はCodex経由で `docs/data/catalog.json` を更新し、PRでレビューします。UUIDは一度生成したものを維持します。学習状態は教材更新後も同じUUIDに紐づきます。詳細は [管理手順](tools/README.md) を参照してください。

**PRを作成しただけでは配信は変わりません。** mainへマージし、GitHub Pagesの配信が完了した後に再読み込みしてください。公開教材は誰でも取得できるので、公開可能な内容だけを追加してください。許可された抽出語彙・訳・短い出典例は掲載できますが、個人の学習記録、バックアップ、字幕全文、鍵やトークンをコミットしないでください。

## バックアップの優先関係
復元は20 MiBまで。全件のID・参照を検証し、確認チェック後に同IDを上書きします。バックアップにない既存データは残します。復元した教材は端末内で保護され、そのIDへの配信側訂正も自動では反映しません。

配信教材へ戻したい場合は「配信教材の最新版に戻す」を確認して実行します。カタログにあるIDだけ保護を解除し、学習状態とカタログにない教材は残します。旧Phase 0データは自動削除せず、確認付き移行を提供します。1タブずつ操作してください。

ローカルURLと公開URLは保存領域が別です。公開サイトへ自動移行・送信しません。必要ならローカルで完全バックアップを保存し、公開サイトで明示復元してください。同じGitHub Pagesホスト上の他サイトとWeb Storageのオリジンを共有するため、機密情報の保管用途ではありません。

## 開発と検証
ビルド・npm不要。リポジトリ直下で以下を実行し、http://127.0.0.1:8000/ を開きます。

```sh
python -m http.server 8000 --bind 127.0.0.1 --directory docs
```

ブラウザテストは `/tests/run-tests.html`。管理環境では `node tools/run-tests.mjs`、教材検証は `node tools/catalog.mjs validate --catalog docs/data/catalog.json`。Nodeで72項目、ブラウザでDOM検証を加えた91項目の回帰テストを含みます。iPhone/iPad実機・音声品質は未確認です。

Pagesはmainブランチの `/docs` を配信し、`.nojekyll` を配置しています。管理用ファイルは配信フォルダ外です。教材生成用プロンプトは [CARD_GENERATION_PROMPT.txt](CARD_GENERATION_PROMPT.txt) を利用してください。

## 読み方練習

学習モードを「読み方練習」にすると、選んだデッキ・検索・学習状態に合うカードからハングルを出題します。`?mode=reading` または `?deck=UUID&mode=reading` で直接開けます。

日本語の読みを入力して答え合わせすると、正誤・登録カナ・日英訳を表示し、韓国語音声を聴けます。ひらがな、カタカナ、半角カナはNFKCとひらがな→カタカナ変換で統一し、空白を除いて照合します。長音・促音・小書き・濁音・句読点は削除しません。別解の自動推測はありません。登録カナとの照合であり、実際の韓国語発音の良否の判定ではありません。

読み欠損・空白だけの読み・needs_reviewのカードは除外して枚数を表示します。未確認の読みは補完しません。空回答は採点せず、IME変換中と確定直後のEnter送信を抑止します。デッキ・検索・絞込・シャッフル・モード変更は練習を最初からやり直します。結果は保存せず、既存の学習状態やバックアップ形式も変更しません。回答時間は計測・表示しません。IME確定直後の送信保護のみ時計を使います。

追加検証：読み方ロジック10件、ブラウザDOM6件。読み方モード追加時はNode58件・ブラウザ66件。IMEイベントは自動テストでも検証しますが、iPhone/iPad実機キーボード・音声品質は別途確認が必要です。

### ヒントと文字の構成図

「ヒント」は先頭のハングル1文字だけ、「解説」は全ての文字の構成図を開きます。回答の前後どちらでも利用でき、入力途中の回答は保持します。もう一度押すと閉じます。ヒントは再表示しても同じ1文字のみです。次問・再練習・デッキやモード切替では閉じて初期化します。

元の文字と、子音（青）・母音（黄）・パッチム（紫）の図を並べ、ラベルも併記します。縦母音は左右、横母音は上下、複合母音は左右と上下の配置を示します。図はフォントを切り分けたものではなく、位置を示す模式的な構成図です。濃音・二重パッチムは保持します。複合母音は配置用の部品と母音全体を併記します。字母からカナを自動生成せず、実際の語の発音変化とは区別します。

分解は[Unicode 16 §3.12](https://www.unicode.org/versions/Unicode16.0.0/core-spec/chapter-3/)の現代ハングル算法に基づき、NFCで合成できる分解済み文字も扱います。単独字母・古いハングル・数字・句読点・空白などは推測せず原文のまま表示します。現代ハングルがない場合は対象外と案内します。カナ正解や意味はヒント・解説からは表示しません。

構成図の追加テストはNode8件（全11172現代文字の初声・母音・パッチム有無のNFD照合を含む）、DOM6件。ローマ字読みの追加検証はNode4件・DOM3件。入門表示の追加検証はNode2件・DOM2件。全体はNode72件・ブラウザ91件です。

### 字母のローマ字読み
構成図の各字母に、音の目安を併記します。「子音・母音・パッチムの読み方一覧」で出題語の字母、子音19・母音21、7つの基本終声音、二重パッチム11字を確認できます。入力を保ち、次問や再設定で閉じます。
[国立国語院のRR](https://www.korean.go.kr/front_eng/roman/roman_01.do)と[標準発音法第8〜14項](https://www.korean.go.kr/kornorms/regltn/regltnView.do?regltn_code=0002)を基準に、初声/母音/終声を別表で管理します。初声ㅇは無音、終声ㅇはng、ㄹは初声r/終声l。終声は語末の基本音で、ㅎや二重パッチムには文脈依存の注記を付けます。これは単語全体の自動ローマ字変換ではなく、連音・同化・単語別例外を計算しません。複合母音は全体の読みをキャプションに表示し、図の位置部品の読みと区別します。

### 入門向けの解説と表
参考動画：[アンニョン韓国語教室「ハングル完全攻略」](https://www.youtube.com/watch?v=8c76RtymHtA)。確認した5:24の字母の組合せ、23:02の「部屋」、51:08の追加母音の見せ方を参考に、独自の文章・図で構成→音の目安→組合せを案内します。動画画像・字幕の転載はありません。
学習用の発音目安（ㄱ k/g・ㄷ t/d・ㅂ p/b・ㅈ ch/j）とRR（g/d/b/j）を別関数・別表示に分け、採点基準は変更しません。「2文字目以降は必ず濁る」「二重パッチムは字母順で読む」「ㅇの前では常に移動」といった万能規則は採用しません。初声ㅇ/終声ㅇ、ㄹのr/l、濃音ㅉのjjは維持します。
子音は基本10/激音4/濃音5、母音は入門用の基本10/追加11に整理（音声学的分類とは別）。基本を先に見せ、追加字母・二重パッチム・RR比較・出典はnative details/summaryで開閉できます。音節ごとの表は部屋/字母/目安の3列です。終声7音に短い口の動きの説明を付け、連音の固定例「옷＋이→오시」は[国立国語院・標準発音法第13項の解説](https://korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=315088&searchCondition=&searchKeyword=)で確認しました。発音の自動変換は追加していません。
